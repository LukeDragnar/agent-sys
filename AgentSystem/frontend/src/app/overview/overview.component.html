Agent System — nền tảng AI assistant dùng chung cho cả team

Hệ thống này là gì?

Agent System là nền tảng giúp cả team dùng chung AI assistant (Claude) để hỗ trợ công việc lập trình hàng ngày — viết code, review, commit, phân tích nghiệp vụ — với context chuẩn của từng dự án đã được setup sẵn.

Thay vì mỗi người tự chat với Claude và phải giải thích lại từ đầu mỗi lần, hệ thống này:

  • Tự load đúng context của project (architecture, patterns, conventions)
  • Tự động lưu toàn bộ conversation vào DB — không cần làm gì thêm
  • Tạo spec/task tự động từ conversation (qua web app)
  • Admin xem được ai đang làm gì, dùng bao nhiêu token, session nào

Các bước setup

1
Clone repo
git clone <repo-url>
cd agent-system
2
Cấu hình paths local
cp projects/local-paths.example.json projects/local-paths.json

Mở projects/local-paths.json, sửa paths theo máy của bạn:

{
  "scrm":          "D:/Projects/scrm",
  "scrm_frontend": "D:/Projects/scrm_frontend",
  "ps_delivery":   "D:/Projects/ps_delivery",
  ...
}

File này đã được gitignore — mỗi người giữ paths riêng, không ảnh hưởng nhau khi pull code.

3
Cài dependencies MCP
cd mcp && npm install && cd ..
4
Tạo tài khoản và cấu hình MCP
node scripts/setup-user.js

Script hỏi: username (đề xuất từ git identity), password, setup key (hỏi lead). Sau khi chạy xong, .mcp.json được tạo tự động.

5
Mở Claude Code
claude

MCP kết nối tự động. Mọi conversation trong terminal tự động được lưu vào DB.

Kiểm tra setup thành công

Vào web app → Sessions → kiểm tra session của bạn xuất hiện sau lần đầu chat.

Các agent và khi nào dùng

/code-agent Viết và sửa code

Mở terminal trong folder project rồi dùng slash command. Claude sẽ tự đọc context đúng project trước khi làm.

/git-agent Commit, branch, push

Dùng sau khi code xong. Claude tạo commit message chuẩn và hỏi trước khi push.

/review-agent Review code

Dùng trước khi tạo PR. Claude đọc qa-code.md của project và review theo đúng checklist.

BA Agent Nghiệp vụ & Spec (mặc định)

Chat bình thường trên web app, không cần slash command. Dùng khi hỏi về luồng nghiệp vụ, phân tích yêu cầu mới, tạo spec cho task.

Tips

Đặt title rõ ràng cho session

Giúp tra cứu sau này dễ hơn. Ví dụ: fix bug NCC/KH tháng 3, feature thêm trạng thái đơn hàng, review PR workflow sprint 12

Mở đúng folder trước khi dùng /code-agent

Claude nhận diện project qua path đang mở. Mở D:\PROJECT\Git\scrm thì Claude tự load context SCRM.

Không cần giải thích lại conventions

Conventions đã được lưu trong projects/<project>/patterns.md và qa-code.md — Claude đọc tự động.

CodeMap la gi?

CodeMap dung Roslyn (C# compiler API) quet toan bo source code, trich xuat cau truc (class, method, property, API endpoint, dependency), luu vao SQL Server. Claude Code query truc tiep thay vi grep → tiet kiem ~90% tokens.

Truoc va sau CodeMap
Khong co MapCo Map
Tokens/cau hoi~10,000~800
Tool calls10-151-2
Thoi gian tim30-60s< 1s
Tim sai fileThuong xuyen0

Cach thuc hoat dong

1Scan — Roslyn doc tung file .cs, parse AST (cu phap), trich xuat class/method/property/endpoint/dependency
→
2Luu DB — Ket qua luu vao SQL Server (3 tables: CodeSymbols, CodeApiEndpoints, CodeDependencies), co index de query nhanh
→
3Query — Claude Code hoac Web UI goi REST API → API query DB → tra ket qua chinh xac
Source code (.cs files)
    |
    | Roslyn parse (KHONG dung AI, $0)
    v
SQL Server (CodeSymbols, CodeApiEndpoints, CodeDependencies)
    |
    |--- REST API  → Web UI (xem tren browser)
    |--- CLI       → codemap.sh (query tu terminal)
    |--- MCP       → Claude Code (tu dong query khi can)

Luu y: Toan bo qua trinh scan va query khong dung AI, khong ton token. Chi la parse code bang compiler API va query SQL.

Khi nao can re-scan?

  • Them class/entity/controller moi
  • Doi ten method, doi route
  • Them enum values moi
  • Khong can re-scan khi chi sua logic ben trong method
