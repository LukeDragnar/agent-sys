Khi query CodeMap, KHÔNG tự đoán project từ path hay context. Phải hỏi user chọn project trước.

**Why:** User muốn rõ ràng, tránh query nhầm project.

**How to apply:** Nếu user chưa nói rõ project, hỏi "Bạn đang hỏi về project nào?" trước khi chạy codemap.sh.
