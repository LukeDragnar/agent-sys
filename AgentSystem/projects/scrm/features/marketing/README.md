# Module: Marketing

> Thu hút & nuôi dưỡng khách hàng tiềm năng (lead/contact) cho SCRM: quản lý nguồn lead, chiến dịch chăm sóc, kết nối sàn TMĐT & mạng xã hội, gửi SMS/Zalo, voucher/khuyến mãi, hoa hồng giới thiệu và báo cáo hiệu quả MKT. Mục lục tính năng — mỗi tính năng 1 folder.
>
> **Mỗi feature folder gồm 4 file:** `summarize.md` (khách + team) · `faq.md` (câu hỏi khách — **chatbot ăn**) · `flow.md` (luồng/test/đào tạo) · `dev.md` (kỹ thuật, chỉ dev).
> Khách hàng / chatbot chỉ thấy `summarize` + `faq`.
