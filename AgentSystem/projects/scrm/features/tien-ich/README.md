# Module: Tiện ích

> **Chợ tiện ích** của đơn vị: nơi chủ shop xem, mua/đăng ký các tiện ích dịch vụ để mở thêm tính năng, và tra lịch sử đăng ký. Mục lục tính năng — mỗi tính năng 1 folder.
>
> **Mỗi feature folder gồm 4 file:** `summarize.md` (khách + team) · `faq.md` (câu hỏi khách — **chatbot ăn**) · `flow.md` (luồng/test/đào tạo) · `dev.md` (kỹ thuật, chỉ dev).
> Khách hàng / chatbot chỉ thấy `summarize` + `faq`.

## Danh sách tính năng
| Tính năng | Mô tả ngắn | Folder |
|---|---|---|
| Quản lý tiện ích | Xem chợ tiện ích, mua/đăng ký (miễn phí kích hoạt ngay, trả phí tạo hợp đồng chờ duyệt), xem/xóa tiện ích đang dùng | [quan-ly-tien-ich/](quan-ly-tien-ich/) |
| Lịch sử đăng ký tiện ích | Nhật ký các lần mua/đăng ký: mã giao dịch, ngày, giá trị, danh sách tiện ích, trạng thái | [lich-su-dang-ky-tien-ich/](lich-su-dang-ky-tien-ich/) |
